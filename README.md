Entry for the [make.fun](https://make.fun) bounty [Everyday Wonder, Two Days to Find the Line](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3): one sentence, at most 200 characters, about a small moment of wonder in everyday life.

> The lift mirror catches me mid-yawn, and the stranger I have been avoiding all week turns out to be me.

## Run

```sh
node main.ts
```

`main.ts` validates the sentence (1–200 characters, one line, no control or zero-width characters, no leading/trailing whitespace) and writes it, with no trailing newline, to `entry.txt` inside `$MAKEFUN_OUTPUT_DIR`, `$OUTPUT_DIR`, or `/output` by default. It then reads the file back and checks it is byte-identical.
